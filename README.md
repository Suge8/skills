# Skills 使用指南

大部分 Skill 会按 description 自动触发；手动工作流直接说名字最稳。

## 日常开发

| 需求 | Skill |
|---|---|
| 项目骨架、文档和验证链体检 | `project-setup` |
| 小范围设计问题先做一次性原型 | `prototype` |
| 想法或计划压力测试 | `grilling`；需要同步术语表和 ADR 用 `grill-with-docs` |
| 构建或完善 CONTEXT.md、ADR | `domain-modeling` |
| 超过一个会话的大型决策工作 | `wayfinder` |
| 从已对齐讨论生成规格和工单 | `to-spec` → `to-tickets` |
| 按规格或工单实现 | `implement`；测试先行用 `tdd` |
| 新建、重设计或打磨 UI | `ui-craft` |
| Bug、性能回归或 flaky | `diagnosing-bugs` |
| 建立或改善验证链 | `set-test-chain` |
| 当前 diff 收口或对标提升 | `optimize` |
| 深模块和架构加深审计 | `improve-codebase-architecture` |
| 提交、版本、Tag 和发布 | `ship` |
| 换会话交接 | `handoff` |
| 用图、树、diff 或 HTML 解释当前主题 | `show-me` |
| 编写 Skill、AGENTS.md、CLAUDE.md | `writing-for-agents` |

Matt 工单流首次使用前运行 `setup-matt-pocock-skills`，配置 GitHub、GitLab 或本地 Markdown tracker。

## 创意与搜索

- `search`：Brave 精确网页、Exa 语义/代码、Context7 官方库文档。
- `gpt-image`：图片和 Logo。
- `video`：导演方案、Remotion 实现或 Grok/Seedance 模型直出。
- `promo`：项目宣传图、截图和演示物料。
- `copywriting`：营销文案；`stop-slop`：去除机械写作痕迹。

## 操作

- `flow-browser-use`：网页操作和诊断。
- `better-computer-use`：桌面应用。
- `ssh`：已授权远程主机。
- `herdr`：用户明确要求操作 Herdr 终端时使用。
- `search-skills`：用户明确点名冷归档 Skill 时定位 Office、Obsidian 等入口。
