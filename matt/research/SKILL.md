description: 针对高可信度的一手来源调查问题，并将调查结果记录为仓库中的 Markdown 文件。当用户希望研究某个主题、收集文档或 API 事实，或将资料阅读工作委托给后台代理时使用。
---

启动一个**后台代理**来进行研究，这样它阅读资料时你可以继续工作。

它的任务：

1. 针对**一手来源**调查问题——官方文档、源代码、规范、第一方 API——而不是它们的二手解读。将每条主张追溯至拥有该主张的来源。
2. 将调查结果写入单个 Markdown 文件，并注明每条主张的来源。
3. 将文件保存到仓库现有的此类笔记目录；遵循现有约定；如果没有约定，则放在合理的位置，并说明保存位置。
